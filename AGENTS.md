# Instructions for coding agents

Read [CLAUDE.md](CLAUDE.md) first: it is the project guide for every agent, not
only Claude. Next.js work also needs `apps/web/AGENTS.md`, if it is present.

**Before adding, changing or deleting a test, read
[docs/testing.md](docs/testing.md).** In short:

- Name the scenario, bug or module contract the test stands behind. If there is
  none, ask, or write no test.
- Never skip, delete or weaken a test, or edit the test rules, to get your change
  through. Never add the `test-policy` label.
