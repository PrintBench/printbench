# PrintBench v0.2.0

PrintBench 0.2.0 adds model packages, creator-selected image previews and
Creality Print handoff, alongside reverse-proxy and container health-check
fixes.

## Highlights

- Group related models and shared files with `.printbench-package.json`
  package sidecars. Packages have their own metadata, previews and detail page
  while preserving each child model.
- Show the creator-selected image throughout model grids and on the model
  detail page.
- Open compatible files directly in Creality Print with the official
  `crealityprintlink://` handoff.
- Preserve explicit ports in forwarded host headers so Next.js Server Actions
  work correctly behind a reverse proxy.
- Probe the web container through its container hostname instead of loopback.

## Upgrade notes

This release includes database migration `0011_model_packages.sql`, which adds
the `models.is_package` column. Back up the database before upgrading. Normal
startup migration handling applies the change automatically; migrations are
forward-only.

The release resolves GitHub issues #21, #22, #23, #24 and #25.
