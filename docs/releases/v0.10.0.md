# PrintBench v0.10.0

## Highlights

- Open **Filaments → Catalogue** to browse the bundled Open Filament Database
  offline. Search with typo tolerance, filter by brand, material and colour, and
  see spool sizes, printing and drying settings, and purchase links where
  available. This release bundles dataset `2026.11.25`. (#119)
- Use **Find in catalogue** when adding a spool to fill in its details. The
  copied values stay editable, and linked spools can be refreshed from the
  catalogue on request. Catalogue updates leave your inventory values as is.
  (#119)
- The shared web and worker container image rebuilds its bundled esbuild
  binaries with Go 1.26.11 to pick up standard-library security fixes. (#118)

## Upgrade notes

- Back up your database and data before upgrading. Startup applies forward-only
  migration `0025`, which adds the catalogue tables and optional catalogue
  links for filaments and spools. Existing inventory remains available at
  **Filaments**.
- The worker imports the bundled catalogue into PostgreSQL after startup and
  after a restore. The catalogue can take a short time to appear. Portable
  backups retain inventory and catalogue links, and the worker rebuilds the
  catalogue tables from the running version's bundle.
- Existing environment variables and Compose settings can be kept. The
  catalogue import works without internet access.
