# PrintBench v0.6.0

PrintBench 0.6.0 adds model source and licence details, improves sidebar spacing,
and tidies application interface copy.

## Highlights

- Show the original model source in Model Information and other model links in
  a separate Additional Links card. Edit source pages, assembly videos, printing
  instructions, designer pages, and custom links.
- Record licence URLs, expiry dates, commercial-use permission, and licence notes.
  Highlight expired licences and those expiring within 30 days. Commercial-use
  permission can be permitted, not permitted, or not recorded.
- Preserve licence details and model links in `.printbench.json` sidecars and
  restore them when rebuilding metadata. Validate dates and link limits before
  saving, and allow only one link of each predefined type.
- Keep the sidebar logo and search control spaced apart at short window heights.
  Navigation scrolls within the remaining space, long instance names truncate,
  and the mobile drawer close button retains its size.
- Replace em dashes in application interface copy with clearer punctuation.

## Upgrade notes

- This release includes additive migration `0015_model_license_details.sql`,
  which adds four nullable columns for licence URLs, expiry dates, commercial-use
  permission, and licence notes. Existing model data is preserved. Back up the
  database before upgrading and apply migrations using the normal deployment flow.
- No new configuration is required. Existing sidecars remain compatible; missing
  licence fields preserve recorded values, while explicit null values clear them
  during restore.
