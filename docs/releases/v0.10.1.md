# PrintBench v0.10.1

## Highlights

- Public HTTP requests can no longer create accounts on invite-only instances.
  First-run setup, invitations and accounts created by an admin continue to work.
  (#125)
- The shared web and worker container image includes a patched version of the
  Undici library bundled with npm. (#124)
- The dedicated PrintBench demo uses a shared account and restores its sample
  library and settings at midnight UTC. (#126)
- The bundled Open Filament Database snapshot is now `2026.11.26`.

## Upgrade notes

- Upgrade the web and worker images together using the normal upgrade procedure.
  This release has no new database migrations, and standard self-hosted instances
  need no changes to their Compose settings, environment or backup procedure.
- If an integration used public account registration, use an admin-created
  account or an invitation link instead.
