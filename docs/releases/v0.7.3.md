# PrintBench v0.7.3

PrintBench 0.7.3 updates application dependencies, development tooling and CI
artifact uploads.

## Highlights

- Update Next.js and its ESLint plugin to 16.4.0, along with Radix UI components
  and Lucide icons.
- Update Drizzle ORM, the AWS SDK, Nano ID and pg-boss within their existing
  major versions.
- Refresh ESLint, TypeScript ESLint, Node.js types and the development process
  runner. TypeScript remains on 5.9.3.
- Update the GitHub Actions artifact uploader to v7 for smoke-test failure
  screenshots.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.7.2. This
  release adds no database migrations, environment changes or backup-format
  changes. Follow the normal backup and container upgrade procedure.
- Source installations should run `npm ci` to install the updated lockfile
  before rebuilding the application.
- If upgrading from an earlier version, also read the
  [v0.7.0 upgrade notes](v0.7.0.md), [v0.7.1 upgrade notes](v0.7.1.md) and
  [v0.7.2 upgrade notes](v0.7.2.md).
