# PrintBench v0.7.5

## Highlights

- Model details show the primary source in the Source field and keep additional
  original model pages under Additional Links. Additional source pages must
  use HTTP or HTTPS. The redundant Source links card has been removed. (#88)
- Update Next.js to 16.4.5, Better Auth to 1.7.17, Three.js to 0.187.0 and
  Chokidar to 6.0.0. This release also refreshes Lucide, the tus upload
  packages, AWS SDK packages, cron-parser and fast-xml-parser. (#86, #90)
- Update ESLint, TypeScript ESLint, Vitest, Tailwind CSS tooling and Node.js
  type definitions. (#89)

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.7.4. This
  release adds no database migrations, environment changes or backup-format
  changes. Follow the normal backup and container upgrade procedure.
- Recreate containers with the v0.7.5 image. For source installations, use
  Node.js 24 or later, run `npm ci` and rebuild both the web app and worker.
- If upgrading from an earlier version, also read the
  [v0.7.4 upgrade notes](v0.7.4.md).
