# PrintBench v0.7.1

PrintBench 0.7.1 clarifies the settings navigation and keeps scan errors visible.
It also strengthens release validation and restores missing historical release notes.

## Highlights

- Find instance-wide options under **Manage → System settings**. Account settings
  remain available from the user menu; the duplicate sidebar entry is removed.
- Failed scan requests keep their error on screen, including when permissions
  have just been revoked. Successful requests still refresh the library view.
- Validate release versions and authored upgrade notes before publication, and
  run browser, worker, integration and container checks against the tagged commit.
- Restore historical notes for v0.1.0 and v0.4.0 and improve contributor and
  support guidance.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.7.0. This patch
  adds no database migrations, environment changes or backup-format changes.
  Existing backup and restore compatibility is unchanged.
- Follow the normal backup and container upgrade procedure. If upgrading from
  an earlier version, also read the [v0.7.0 upgrade notes](v0.7.0.md).
- Account settings are now reached through the user menu. Administrators use
  **Manage → System settings** for instance-wide options.

This release includes approved pull requests #70 and #71, together with changes
already on main since v0.7.0.
