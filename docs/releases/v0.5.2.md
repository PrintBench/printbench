# PrintBench v0.5.2

PrintBench 0.5.2 brings local uploads and model-site imports into one workspace
and simplifies connecting a MakerWorld account.

## Upload and import

- Choose **Save to library** once for local files, folders, ZIP archives, or
  model links. Uploads and imports now share one compact card.
- Paste a MakerWorld, Printables, or Thingiverse URL below the upload area.
  Connection guidance appears only for the detected site.
- The destination library stays locked while an upload or import is running.
  Existing resumable uploads, folder structure, ZIP extraction, and import
  progress are preserved.
- Add spacing below **Save to library** and **Model page URL** for readability.

## Connect MakerWorld

1. Open **Account settings → MakerWorld** and sign in with your Bambu account
   email and password.
2. Enter an email verification code or authenticator code if requested.
3. After connecting, open **Upload**, select a library, paste a model URL, and
   choose **Import model**.

Settings includes connection checks, reconnect, and disconnect. The existing
cookie method remains available under **Advanced: use a cookie instead**, with
clearer browser instructions.

Passwords and verification codes are never stored. Account tokens and pending
verification details are encrypted per user. Challenges expire after ten minutes;
sign-in attempts are rate limited, and cancelled or replaced challenges cannot
save a token later.

## Upgrade notes

- No new database migrations or configuration changes are required. Existing
  saved MakerWorld cookies continue to work.
- Direct sign-in supports Global `makerworld.com` accounts through undocumented
  Bambu endpoints; it is not OAuth. China-region accounts and Google/Apple-only
  sign-in are not supported by this flow. Use the advanced cookie method when
  direct sign-in is unavailable.
- Real-account sign-in has been confirmed. An authenticated model download using
  the new connection has not yet been separately confirmed; the existing import
  pipeline is unchanged.
