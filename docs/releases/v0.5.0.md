# PrintBench v0.5.0

PrintBench 0.5.0 adds model source imports and account recovery, improves model
processing feedback, and fixes queued model moves.

## Highlights

- Import models from MakerWorld, Printables, and Thingiverse, with source
  credentials managed in Account settings. Import embedded 3MF metadata and
  artwork while preserving curator edits.
- Change your password in Account settings, including for viewer accounts.
  Admins can issue private, single-use recovery links without SMTP, and server
  operators can recover an account with the packaged `npm run auth:reset` command.
  Password changes and recovery serialize credential updates and revoke sessions.
- Show processing labels and update model previews automatically as renders finish.
- Start the web job queue before moving a model so browser-initiated moves run.
- Put 3MF files first in the model file tree while preserving unique node keys.
- Update approved production and development dependencies.

## Upgrade notes

- This release includes database migrations `0012_tidy_impossible_man.sql`,
  `0013_aromatic_bulldozer.sql`, and `0014_pretty_norman_osborn.sql` for embedded
  metadata state, source imports, and encrypted provider credentials. Back up the
  database before upgrading and apply migrations using the normal deployment flow.
- See [model import setup](../model-imports.md) for provider credentials and
  supported import behavior. Password recovery requires no additional migration.
- Recovery links expire after one hour and can be used once. Share each link
  privately with the account owner.
