# PrintBench v0.3.0

PrintBench 0.3.0 improves large-library reliability and model file browsing,
and refreshes the project's development, runtime and release dependencies.

## Highlights

- Browse model files in collapsible directory trees while preserving download,
  slicer handoff, printer permissions and missing-file behavior.
- Opt in to writable in-place libraries for metadata sidecars without removing
  the default read-only protection or granting Nginx write access.
- Parse dense 3MF geometry with bounded allocations and reject oversized
  compressed or expanded inputs before they exhaust worker memory.
- Enable opt-in worker memory diagnostics with `WORKER_MEMORY_LOG=1` to trace
  job and scan phases on large installations.
- Update the CI Node setup action, the Nginx image, development dependencies,
  and production minor/patch dependencies.

## Upgrade notes

- Existing in-place libraries remain read-only. Set `LIBRARY_MODE=rw` only when
  PrintBench should write metadata sidecars. If access relies on a host group,
  add that library's numeric GID to the web and worker services in a deployment
  override.
- 3MF inputs now have explicit compressed-input and combined expanded-data
  limits. Files over those limits remain indexed and downloadable, but analysis
  and thumbnail generation report an error.
- Worker memory logging is disabled by default and is intended for diagnostics,
  not continuous production logging.
