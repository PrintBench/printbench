# PrintBench v0.5.1

PrintBench 0.5.1 fixes the Coolify deployment failure introduced by the library
mount configuration in 0.5.0.

## Fix

- Use explicit YAML bind mount fields so Coolify parses the library source,
  target, and read-only setting independently. This resolves the deployment
  error `Invalid volume source: contains forbidden character '${'`.
- Keep existing collections read-only by default and nginx read-only in all
  configurations. Web and worker can still write metadata sidecars when enabled.

## Upgrade notes

- `LIBRARY_READ_ONLY` replaces `LIBRARY_MODE`. If you used `LIBRARY_MODE=rw`, set
  `LIBRARY_READ_ONLY=false` to retain sidecar writes. For read-only collections,
  use `LIBRARY_READ_ONLY=true` or leave it unset.
- Keep your existing `LIBRARY_PATH`, database volume, and data volume when
  redeploying. Load the updated compose file in Coolify before redeploying.
- No new database migrations or application changes are included compared with
  0.5.0.
