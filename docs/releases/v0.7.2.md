# PrintBench v0.7.2

PrintBench 0.7.2 fixes production build tracing for runtime library paths.

## Highlights

- Keep managed libraries, development library discovery and directory browsing
  paths out of the standalone server bundle. This removes three Turbopack
  filesystem warnings and avoids tracing the whole project into the bundle.
- Library path resolution, storage access and containment checks are unchanged.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.7.1. This patch
  adds no database migrations, environment changes or backup-format changes.
  Follow the normal backup and container upgrade procedure.
- Earlier Docker Compose deployments must pass the same existing
  `BETTER_AUTH_SECRET` to web and worker and recreate the worker to apply it.
  The shared-secret configuration already shipped in v0.7.1; PR #74 reconciles
  the original fix's history without further code changes. Keep the existing
  secret so stored MakerWorld cookies and Thingiverse tokens remain readable.
- If upgrading from an earlier version, also read the
  [v0.7.0 upgrade notes](v0.7.0.md) and [v0.7.1 upgrade notes](v0.7.1.md).
