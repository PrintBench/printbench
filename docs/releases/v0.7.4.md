# PrintBench v0.7.4

PrintBench 0.7.4 refreshes application dependencies and development tooling,
including security fixes in the locked dependency tree.

## Highlights

- Update Next.js to 16.4.3 and refresh transitive dependencies including Vite,
  source-map-js and brace-expansion with the security updates from PR #82.
- Update React and React DOM to 19.3.1, Better Auth to 1.7.10, Zod to 4.6.7,
  and the Radix UI components, Lucide icons, AWS SDK, cron-parser and pg-boss.
- Refresh Playwright, Vitest, Prettier, TypeScript ESLint, Node.js types and
  the Next.js ESLint plugin. TypeScript remains on 5.9.3.

## Upgrade notes

- No additional upgrade action is needed when upgrading from v0.7.3. This
  release adds no database migrations, environment changes or backup-format
  changes. Follow the normal backup and container upgrade procedure.
- Recreate containers using the new image to apply the dependency fixes.
  Source installations should run `npm ci` and rebuild both the web app and
  worker. Updating source files alone does not patch an existing deployment.
- If upgrading from an earlier version, also read the
  [v0.7.3 upgrade notes](v0.7.3.md) and the earlier release notes linked there.

This release includes approved pull requests #80, #81 and #82. Pull request #7
remains excluded by `do not merge`.
