# PrintBench v0.7.6

## Highlights

- With read access to the private app and nginx packages,
  [sign in to GitHub Container Registry](https://github.com/PrintBench/printbench/blob/v0.7.6/docs/deployment.md#quick-start-on-this-computer)
  and start a local PrintBench instance with the release's
  [Compose file](https://github.com/PrintBench/printbench/releases/download/v0.7.6/compose.yaml)
  and `docker compose up -d`. Open <http://localhost:8080> to create an admin
  account, then upload models to a managed library or mount an existing
  collection read-only. (#94)
- The Compose file pins the app and nginx images to v0.7.6. It generates the
  database password and application secret on first startup and keeps them
  across container recreations.

## Upgrade notes

- Existing deployments can keep their Compose configuration and follow the
  normal backup and container upgrade procedure. This release requires no
  database migrations, environment changes or backup-format changes.
- For quick-start installs, back up the `credentials`, `pgdata` and `data`
  volumes together. Keep the credentials volume when recreating containers
  or replacing `compose.yaml` for a later upgrade.
