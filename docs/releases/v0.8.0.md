# PrintBench v0.8.0

## Highlights

- Send models from MakerWorld, Printables or Thingiverse straight to a writable
  library with the [PrintBench browser clipper](../model-imports.md#browser-clipper).
  The release includes a Chrome and Edge ZIP and a signed Firefox add-on. (#99)
- Keep a running log on a model and link notes to individual prints. Attach
  photos to the model or a specific print to record results. (#107, #108)
- Open a model in your slicer from its header, jump to its library's filtered
  search, and see the unfinished print queue count in the navigation. The user
  menu now links to the user guide. (#103, #104, #105, #106)
- See the installed version and check for a newer stable release in
  **System settings → Updates**. Admins also see available updates in the
  activity panel. (#111)
- Updated application and development dependencies and made backup test
  teardown more reliable. (#97, #109, #110)

## Upgrade notes

- Back up your database and data volume before upgrading. Startup applies
  forward-only migrations for model notes, photos and browser clipper tokens.
  Use the matching app and nginx images, or apply the new internal photo route
  from `docker/nginx.conf` to a customised nginx configuration that serves
  PrintBench's internal file routes.
- In-app portable backups now include uploaded photos even when managed library
  files are excluded. Include `/data/photos` in manual backups. Generate new
  browser clipper connection tokens after restoring a portable backup.
- Existing environment variables and Compose settings can be kept. Update
  checks are on by default and read the public GitHub release endpoint. Disable
  **Check for new versions** in **System settings → Updates** if you want to
  turn off that request.
